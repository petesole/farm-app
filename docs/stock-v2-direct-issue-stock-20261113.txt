Direct Issue availability — development change, 13/11/2026

Product choices show available stock and its unit for the issuing owner, using the existing posted warehouse balance. Selected product rows retain the same Available quantity. Zero-stock choices are disabled. Other owners' stock is not treated as available to this issue.

Entering more than the displayed quantity shows Exceeds available stock and disables posting. The exact available balance is accepted. Product selection refreshes stock. The existing transactional database negative-stock guard remains authoritative if another user issues stock concurrently. A rejected issue refreshes the displayed balance while preserving typed quantities and the rest of the form; the existing previous-save verification path remains available for uncertain results.
